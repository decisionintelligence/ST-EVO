# Contributing to ST-EVO

Thank you for your interest in contributing to ST-EVO! This document provides guidelines for contributing to the project.

## How to Contribute

### Reporting Issues

- Use the GitHub issue tracker to report bugs
- Clearly describe the issue including steps to reproduce
- Include the version of Python and PyTorch you're using

### Pull Requests

1. Fork the repository
2. Create a new branch for your feature (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Add tests if applicable
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Code Style

- Follow PEP 8 guidelines
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Keep functions focused and concise

### Testing

- Ensure all existing tests pass
- Add new tests for new features
- Run tests with: `pytest`

## Development Setup

```bash
# Clone your fork
git clone https://github.com/yourusername/STEVO.git
cd STEVO

# Install in development mode
pip install -e .
```
